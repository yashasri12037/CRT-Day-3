# CRT Class – Python Problem Solving 💻

## 📌 Overview

As part of my Campus Recruitment Training (CRT), I practised Python programming problems to strengthen my problem-solving skills and logical thinking.

This session focused on arrays, lists, strings, and mathematical operations. I learned different approaches to solving programming problems and improved my understanding of Python concepts through practical implementation.

## 📚 Programs Covered

### 1. Top K Frequent Elements
**File:** `Top K frequent element.py`

**Description:**
Find the K most frequently occurring elements in a given array.

**Concepts Learned:**
- Python lists and arrays
- Counting element frequencies
- Dictionaries and frequency counting
- Sorting and problem-solving techniques

**Learning Outcome:**
Understood how to count the occurrences of elements and identify the most frequent elements in a collection.

---

### 2. Rotate Array
**File:** `Rotate Array.py`

**Description:**
Rotate the elements of an array by a given number of positions.

**Concepts Learned:**
- Array manipulation
- List indexing and slicing
- Loops and list operations
- Handling rotation positions

**Learning Outcome:**
Learned how to rearrange array elements through rotation and explored different approaches to solving array manipulation problems.

---

### 3. Reverse Integer
**File:** `Reverse Integer.py`

**Description:**
Reverse the digits of a given integer and return the reversed number while considering the problem's constraints.

**Concepts Learned:**
- Arithmetic operators
- Modulus (`%`) and integer division (`//`)
- Loops and conditional statements
- Digit extraction and number reversal

**Learning Outcome:**
Improved my understanding of mathematical operations and learned how to manipulate the digits of an integer using Python.

---

### 4. Anagram
**File:** `Anagram.py`

**Description:**
Check whether two strings are anagrams of each other. Two strings are anagrams if they contain the same characters with the same frequencies, regardless of their order.

**Example:**
- Input: `listen`, `silent`
- Output: `True`

**Concepts Learned:**
- String manipulation
- Character frequency counting
- Sorting strings
- Conditional statements

**Learning Outcome:**
Learned how to compare strings and determine whether they contain the same characters in different arrangements.
